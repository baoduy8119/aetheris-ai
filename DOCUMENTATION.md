# 🌌 AETHERIS 2.0 — Next-Gen Specialized AI & Tech Startup Template

> **AETHERIS 2.0** is an ultra-premium, heavily animated Next.js 14+ multipurpose template engineered for high-value AI software verticals. Built with **Spatial Computing UI**, **Tech-Brutalism**, **Lenis Smooth Scroll**, **GSAP ScrollTrigger**, and **Framer Motion**.

---

## 🚀 8 Specialized Vertical Homepages (Zero Template Repetition)

Unlike generic AI templates that recycle the same chat prompt box, **AETHERIS 2.0** features **8 completely distinct, high-conversion software suites**:

| Route | Vertical | Signature Interactive Component & Realism |
| :--- | :--- | :--- |
| `/` | **01. Neural DAW & Generative Audio** | **Interactive Multi-Track DAW**: Real-time playhead, solo/mute stems (Vocals, Synth, Bass, Drums), and 48kHz audio DSP. |
| `/home-image-gen` | **02. 3D NeRF & Gaussian Splats** | **Interactive 3D WebGPU Viewport**: Orbit, zoom, point cloud density controllers, and USDZ/PLY exporters. |
| `/home-developer-api` | **03. Quant Trading & HFT Terminal** | **Live Financial HUD**: Live synthetic candlestick charts, order book DOM depth ladder, and Sharpe ratio telemetry. |
| `/home-personal-os` | **04. Physical Robotics & LiDAR Tele-Op** | **LiDAR Sensor Map & Actuators**: 256-beam proximity radar sweep and 6-DOF joint angle telemetry gauges. |
| `/home-copywriting` | **05. Legal AI & Smart Contract Redlines** | **Split-Pane Redline Diff Editor**: Automated indemnity risk scoring, strike-through redlines, and Delaware case law citations. |
| `/home-voice-audio` | **06. Bio-Medicine & Molecular Folding** | **Macromolecular Inspector**: 3D protein ribbon visualizer, pLDDT confidence scores, and binding affinity radar. |
| `/home-data-analytics` | **07. High-Frequency Telemetry** | **High-Density Data Stream**: Dual-layer SVG spline charts with interval filters (`1H`, `24H`, `7D`). |
| `/home-cybersecurity` | **08. Autonomous Cyber Defense** | **Tactical Defense Radar**: 360° rotating radar sweep and live incident intercept stream terminal. |

## 🛠 Tech Stack & Core Libraries

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript (Strict Mode)
- **Styling**: Tailwind CSS
- **Smooth Scroll**: `@studio-freight/lenis`
- **Animation Orchestrator**: `GSAP` & `ScrollTrigger`
- **UI Physics**: `Framer Motion`
- **3D Parallax Tilt**: `react-parallax-tilt`
- **Icons**: `Lucide React`
